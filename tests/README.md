Before the system and UI layers: build the images (`docker compose build`) and the synthetic test disk:

```bash
docker run --rm -v "$PWD:/repo" -w /repo python:3.11-slim sh scripts/test-image/make-test-image.sh
sh scripts/test-image/fetch-samples.sh   # public samples (dfVFS, Plaso, python-evtx), ~400 MB, pinned by SHA-256,
                                         # and the samples disk built from some of them
docker run --rm --privileged -v "$PWD:/repo" -w /repo python:3.11-slim sh scripts/test-image/make-ntfs-image.sh   # the NTFS disk
sh scripts/test-image/make-plaso-timeline.sh   # Plaso's timeline of the disk (pinned Plaso image), for the import tests
```

Without the samples, the sample-based checks are reported as skipped. `SECTIONS=07b,12b sh tests/system/run.sh` runs only those system-test sections (after the setup sections 02, 04, 06 and 07).

## System tests (`tests/system`)

`run.sh` starts an isolated copy of the stack (`compose.yml`: its own MongoDB, Redis and storage volume, no host ports), runs `dfip_full_test.py` inside the backend container, then removes the stack. Nothing in a running DFIP is touched.

Results are checked against ground truth that does not come from DFIP: the known contents of the test disk (`scripts/test-image/make_artifacts.py` and the manifest it leaves next to the image; the deleted payroll export is regenerated byte for byte), Sleuth Kit (`mmls`, `fls -z America/New_York`, `icat`, `mactime`), regipy and libregf run directly on the image, objdump, ExifTool, osslsigncode, UPX and clamscan on the test disk's programs, qemu-img (virtual disks), vshadowinfo and fls on shadow copies written out, independent VHD and LUKS1 readers written in the test, and the pinned public samples.

## Desktop app

Install the published setup (`storage/downloads/*_x64-setup.exe`), then start it with remote debugging and drive it with Playwright over CDP:

```powershell
$env:WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS = '--remote-debugging-port=9333'
& "$env:LOCALAPPDATA\DFIP Investigator\dfip-investigator.exe"
```

Check: the app opens on sign-in on every launch; the workstation panel shows the host; "Verify a local copy" on an evidence item reports a match for the same image file; Change password opens; sign-out returns to the sign-in page.
